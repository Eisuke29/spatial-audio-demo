# 立体音響デモ

## メイン：聴覚リダイレクション

**[redirect.html](redirect.html)** は、机のカメラで色シールを追跡する聴覚リターゲティングのプロトタイプです。2.1では一画面で順に準備し、A/B/Cをカメラ映像に重ねます。1回体験、音なしの到達誤差、4条件の比較記録を選べます。接触は自己申告で、試行中の位置遮蔽・中断と再開・CSV/JSON出力に対応しています。

公開版は **<https://eisuke29.github.io/spatial-audio-demo/redirect.html>** から開けます。カメラを使うため、ローカルで試す場合は次のサーバーから開いてください。

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

## 旧マウス予備実験

**`experiment.html`** を開くと、頭を固定して「音で手の行き先が変わるか」を試せます。

- マウスで広く動かす／画面内ドラッグ／iPadのタッチ
- 実物なしの到達、または登録した実物Pへの接触タスク
- 音なし・A固定・A→P移動・手相対のP誘導の4条件
- 試行を均等に組んで順序をランダム化。0%と両方向のずらしを含む
- 練習だけ答え合わせ、本番中は条件と正解を隠す
- 到達位置・軌跡・回答を端末内に保存し、CSV／JSONで書き出し

手順・入力の調整・測定の限界は [EXPERIMENT.md](EXPERIMENT.md) にあります。マウスの座標は相対入力であり、手の絶対位置や実寸cmではありません。接触は自己申告です。

## 位置当てデモ

上から見た円の中をクリックすると、その場所から音が鳴るブラウザ用のデモです。ヘッドホンかイヤホンで聞いてください。

## できること

- 円の中をクリック・ドラッグして音源を置く（真ん中が聞く人の頭、上が正面）
- 音の種類（標準のパルス状ノイズ・ピッ音・ピンクノイズ・カチカチ・持続音）、音量、高さを変える
- 立体音響の方式（HRTF／左右の振り分けだけ）と、距離で音を小さくするかを切り替える
- 配置プリセット：正面・真右・真後ろ・前方の左右にA・P・B・右側の前後にA・P・B
- 当てっこモード：音源を隠してランダムに鳴らし、聞こえた場所をクリックすると、正解とのずれ（方向・距離・位置）を表示する

## しくみ

Web Audio API の PannerNode（panningModel = HRTF）を使っています。聞く人を原点に置き、正面を −z 方向にしています。ライブラリは使っていません。

## ローカルで動かす

`index.html` をブラウザで開くだけで動きます。
